# Next.js Documentation

This documentation covers **Next.js v13+** with the App Router.

Sample projects and most examples in the documents are from **Next.js & React - The Complete Guide** course by **Maximilian Schwarzmüller**

---
## Prerequisites

- **[Node.js](https://nodejs.org/) v18+**
- Basic knowledge of React (components, props, state, hooks)
- Familiarity with HTML, CSS, and JavaScript/TypeScript

---
## Quick Start

```bash
# Create a new Next.js app
npx create-next-app@latest my-app

# Navigate into the project
cd my-app

# Start the development server
npm run dev
```
